macOS tints a template image itself, so one asset covers light, dark, the open-menu highlight and reduced transparency. The Wi-Fi, battery and Control Center glyphs are stand-ins for checking weight and optical size.

Construction

The display is the noun. The brackets are the verb: two corners of a selection, the same idiom as a resize handle, so the glyph says resolution rather than monitor.

18 × 18 pt
Apple’s status-item grid. Ink spans 16 × 14 with a 1 pt safety margin, matching the optical size of Wi-Fi and battery.
screen 15 × 10
3 : 2 rounded rectangle, radius 2. Stroke centred on x 1.5 and y 2.5 so it fills whole pixels at 1x.
brackets 3 px
Three-pixel arms, one pixel thick, square ends and mitred corners. Set 2 px in from the screen edge and mirrored about the screen centre (9, 7.5). The same geometry is cut out of the solid weight.
neck 2 px
The glyph is centred on x 9, a whole pixel. A 1 px neck there would straddle two columns and blur, so the neck is 2 px wide and lands cleanly on columns 8 and 9.
base 8 px
1 px line with square ends on row 15, from column 5 to 12. Keeps the silhouette from collapsing into a plain rectangle at 1x.

// AppKit
let item = NSStatusBar.system
    .statusItem(withLength: NSStatusItem.squareLength)
let glyph = NSImage(named: "MenuBarIcon")!
glyph.isTemplate = true   // catalog sets this too
item.button?.image = glyph

// SwiftUI
MenuBarExtra("ForceRes", image: "MenuBarIcon") {
    // resolution menu
}

Both imagesets are marked as template images in the catalog. Keep the SVGs as the source and re-rasterise from them if the grid changes.
